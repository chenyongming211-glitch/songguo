# 松果AI当前产品需求基准

## 1. 一句话需求

松果AI是面向小学阶段孩子的专属 AI 学习陪练产品，不是重新做大模型，也不是搜题工具。它要给大模型加上学生长期学习档案、错题整理、复习计划、家长报告和数据隔离。

## 2. 产品定位

松果AI要做的是专属 AI 教师。默认 AI 老师叫松鼠博士。

核心体验：

```text
孩子拍照或输入一道题
-> AI 不直接给答案
-> AI 像老师一样一步步追问
-> 孩子尝试回答
-> AI 根据孩子回答继续引导
-> 做完后生成同类题
-> 系统记录错题、错因、薄弱点
-> 家长看到本次反馈和长期报告
```

2026-05-10 追加：上述“拍照或输入一道题”升级为统一 Learning Submission 模型。产品和后端流程都不区分单题还是多题；无论孩子提交了多少道题，都走同一套学习提交、判题、资产沉淀和错题队列陪练流程。

2026-05-10 追加：前端不要求孩子或家长区分数学、语文、英语或具体题型。小程序只提供统一做题入口；后端负责自动识别学科、题型和任务意图，并路由到对应 TutorGraph。详见 `v0.2-auto-subject-routing-plan.md`。

```text
开始做题
-> 拍照 / 语音 / 输入
-> 系统识别 1 到 N 道题
-> 系统自动识别学科和题型
-> 先沉淀所有题的学习资产
-> 正确题记录掌握证据
-> 错误题记录错因和薄弱点
-> 松鼠博士按错题队列逐题陪练
-> 陪练完成后记录“已纠正但需近期复习”
-> 经过 1-2 次复习练习独立答对后，再沉淀为该题型已掌握
-> 全部错题完成后生成本次总结和家长反馈
```

## 3. 核心差异化

松果AI的壁垒不来自“大模型更强”，而来自产品层能力：

```text
1. 每个孩子独立学习档案。
2. 每道错题结构化沉淀。
3. 长期错因和薄弱点追踪。
4. 自动生成复习建议。
5. 家长能看懂孩子为什么不会。
6. 学生数据隔离。
7. AI 不直接变成答案机器。
```

## 5. 当前 v0.1 MVP 主线

v0.1 只优先验证一个成熟闭环：

```text
小学数学学习提交
-> 识别 1 到 N 道题
-> 批量判题
-> 正确题记录 MasteryEvidence
-> 错误题进入错题队列
-> AI 自然引导
-> 规则/护栏防答案泄露
-> 答对后生成 1-3 道同类题
-> 陪练完成后更新掌握证据，但不直接标记题型完全掌握
-> 题型进入近期复习计划，1-2 次复习练习独立答对后再标记已掌握
-> LearningDeposit 落库
-> 家长端能看到反馈
```

但产品入口不应被限制为数学。v0.2 的核心整改是：

```text
统一做题入口
-> 后端自动识别 math / chinese / english / unknown
-> math 继续进入现有数学强闭环
-> chinese 进入阅读、造句、表达修改等轻量 TutorGraph
-> english 进入翻译、语法、造句等轻量 TutorGraph
-> unknown 进入澄清型 TutorGraph
```

当前不优先做：

```text
完整英语知识体系
完整语文作文大闭环
老师端
机构 SaaS
完整支付
复杂多租户后台
动画视频
```

## 6. AI 交互原则

大模型负责：

```text
理解当前题
生成自然追问
解释关键点
生成同类题
生成家长可读总结草稿
```

松果AI后端负责：

```text
当前题会话管理
学生长期记忆
错题和错因归档
复习计划
家长报告
权限和数据隔离
答案泄露检查
模型调用日志和成本控制
```

2026-05-11 追加：松鼠博士每轮回复必须先遵守 Tutor State Contract 的学习准备度判断。后端不靠具体关键词判断孩子是否要暂停，而是要求大模型结构化输出 `learner_readiness`、`child_answer_status` 和 `teacher_move`；当孩子当前不适合继续学习时，模型应进入 `LEARNING_PAUSED` 或 `PRACTICE_PAUSED`，不继续推进题目。后端负责状态承接和一致性校验，不能把正常模型回复改写成固定教学话术。

规则和状态机不应该在前端显示成固定步骤。它们只做：

```text
答案护栏
规则判题
Schema 校验
失败 fallback
节省 token
```

## 7. 当前最重要的开发要求

下一步开发必须继续围绕：

```text
真实 DeepSeek 小程序体验
黄金数学题集评测
自动学科识别和智能体路由
家长反馈闭环
学生长期学习档案
复习计划
```

不要继续扩展新概念。核心目标是先证明：

```text
孩子做一道题时，松鼠博士真的像老师一样引导。
题目结束后，松果AI真的把学习资产沉淀下来。
```
