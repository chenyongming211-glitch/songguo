# v0.2 本地测试基线与备案期间开发边界

备案完成前，不把开发节奏压在 `api.songguoxue.com` 真机连通性上。本阶段目标是在本地后端和微信开发者工具里收口统一提交链路，备案通过后只切换合法域名做真机验收。

## 当前本地基线

- 大模型默认使用 `deepseek-v4-flash`，不再使用旧的 `deepseek-chat` 默认值。
- 前端继续只提供拍照、语音、输入三个入口，不要求孩子先选择数学、语文或英语。
- 后端统一进入 Learning Submission，再由 IntentRouterAgent 自动识别学科、题型和意图。
- 数学题进入 MathMistakeTutorGraph。
- 语文、英语和通用学习问题进入基础陪练闭环，并由 BasicSubjectRubricEvaluator 先做 rubric 判分和反馈。
- 拍照入口先生成可编辑识别草稿，不直接创建旧的 photo-review 学习会话。
- 真实拍照 OCR 默认目标切到阿里云读光教育 OCR；阿里云 MaaS OpenAI-compatible 视觉模型作为临时兜底，先使用 `qwen3.6-flash`。

## 拍照 OCR / 视觉识别链路

`POST /api/v1/learning/submissions/photo-draft` 作为统一提交的拍照草稿接口。

接口职责：

- 保存上传图片为学习 artifact。
- 调用本地 fixture OCR、阿里云教育 OCR 或配置的视觉模型 OCR。
- 返回 `raw_text` 供小程序确认页编辑。
- 返回 `items`，保留多题拆分后的 `question_text`、`child_answer`、`work_steps` 和 `confidence`。
- 返回整体 `confidence`、`image_refs`、`ocr_provider`、`ocr_model` 和 `ocr_source`。
- 不创建旧的学习会话，用户确认后再调用 `/submissions` 和 `/submissions/{id}/confirm`。

本地教育 OCR 配置：

```bash
SONGGUO_PHOTO_OCR_PROVIDER=aliyun_edu
SONGGUO_ALIYUN_EDU_OCR_ACCESS_KEY_ID=your_access_key_id
SONGGUO_ALIYUN_EDU_OCR_ACCESS_KEY_SECRET=your_access_key_secret
SONGGUO_ALIYUN_EDU_OCR_ENDPOINT=https://ocr-api.cn-hangzhou.aliyuncs.com
SONGGUO_ALIYUN_EDU_OCR_REGION=cn-hangzhou
SONGGUO_ALIYUN_EDU_OCR_SCENE=auto
SONGGUO_ALIYUN_EDU_OCR_ROUTER_MODE=auto
SONGGUO_ALIYUN_EDU_OCR_MAX_SECONDARY_ACTIONS=1
SONGGUO_ALIYUN_EDU_OCR_CUT_TYPE=question
SONGGUO_ALIYUN_EDU_OCR_IMAGE_TYPE=photo
SONGGUO_ALIYUN_EDU_OCR_SUBJECT=default
SONGGUO_ALIYUN_EDU_OCR_OUTPUT_ORICOORD=true
SONGGUO_ALIYUN_EDU_OCR_NEED_ROTATE=true
SONGGUO_ALIYUN_EDU_OCR_TIMEOUT_SECONDS=12
SONGGUO_ALIYUN_EDU_OCR_FALLBACK_PROVIDER=none
```

视觉模型兜底配置：

```bash
SONGGUO_PHOTO_OCR_PROVIDER=vision
SONGGUO_VISION_BINDING=aliyun
SONGGUO_VISION_MODEL=qwen3.6-flash
SONGGUO_VISION_HOST=https://token-plan.cn-beijing.maas.aliyuncs.com/compatible-mode/v1
SONGGUO_VISION_API_KEY=your_api_key_here
SONGGUO_VISION_TIMEOUT_SECONDS=20
```

模型选择：

- `auto`：教育 OCR 默认场景，由 `EducationOcrRouter` 先走 `PaperStructed`，结构为空时回落到 `PaperCut`，答案覆盖不足时最多追加一次 `PaperOcr`。
- `paper_cut`：整页多题切分，适合结构化失败时兜底。
- `oral_calculation`：口算专项，可直接返回 `right/wrong/unknown` 作为客观题判题证据。
- `paper_structed`：精细结构化切题，是当前正常整页作业的自动主路径。
- `qwen3.6-flash`：当前默认，适合私测阶段优先控制延迟和成本。
- `qwen3.6-plus`：照片复杂、字迹较差或多题拆分不稳定时优先切换。
- `deepseek-v4-flash` / `deepseek-v4-pro`：继续用于文本推理、路由和 rubric，不作为拍照 OCR 默认模型，因为当前套餐描述里不包含视觉理解能力。

## OCR 评测基线

OCR 评测样本放在 `data/evaluation/ocr_samples/`：

- `manifest.jsonl` 是样本清单，每行一个样本。
- `fixtures/` 保存可稳定回归的本地文本 fixture。
- 真实手机照片可以放到 `images/`，并在 `manifest.jsonl` 中新增对应样本行。

本地 fixture 冒烟：

```bash
PYTHONPATH=/Users/chen/code python scripts/songguo_run_ocr_eval.py --provider deterministic
```

真实视觉模型评测：

```bash
PYTHONPATH=/Users/chen/code python scripts/songguo_run_ocr_eval.py --provider vision --manifest data/evaluation/ocr_samples/manifest.jsonl --json
PYTHONPATH=/Users/chen/code python scripts/songguo_run_ocr_eval.py --provider aliyun_edu --manifest data/evaluation/ocr_samples/manifest.jsonl --json
```

没有真实手机照片时，可以先生成合成压力样本，模拟清晰图片、倾斜阴影、模糊低对比和 JPEG 压缩：

```bash
PYTHONPATH=/Users/chen/code python scripts/songguo_generate_ocr_stress_samples.py --output /private/tmp/songguo_ocr_stress_full
PYTHONPATH=/Users/chen/code python scripts/songguo_run_ocr_eval.py --provider vision --manifest /private/tmp/songguo_ocr_stress_full/manifest.jsonl --json
```

合成压力样本只能提前暴露 OCR 链路、题干/答案拆分和模型结构化问题，不能替代真实孩子手写照片验收。

图片到提交闭环的端到端评测：

```bash
PYTHONPATH=/Users/chen/code python scripts/songguo_run_photo_submission_e2e_eval.py --provider deterministic --agents deterministic
PYTHONPATH=/Users/chen/code python scripts/songguo_run_photo_submission_e2e_eval.py --provider vision --agents env --manifest /private/tmp/songguo_ocr_stress_full/manifest.jsonl --json
PYTHONPATH=/Users/chen/code python scripts/songguo_run_photo_submission_e2e_eval.py --provider aliyun_edu --agents env --manifest /private/tmp/songguo_ocr_stress_full/manifest.jsonl --json
```

该评测会覆盖：

- 图片 OCR 是否识别出题目和孩子答案。
- OCR 多题拆分数量、题干和答案是否匹配。
- `subject=auto` 后是否识别到预期学科。
- 是否路由到数学、语文或英语对应 Tutor。
- 数学是否进入判题；语文/英语是否进入 rubric。
- 最终是否避免 `needs_manual_confirm`。

当前评测指标：

- `pass_rate`：样本整体通过率。
- `item_count_match_rate`：多题拆分数量匹配率。
- `answer_coverage_rate`：OCR 实际抽出孩子答案的题目占比。
- `ocr_action_counts`：本轮使用的教育 OCR action 分布，用于看是否产生额外调用成本。
- `question_match_rate`：题干文本匹配率。
- `answer_match_rate`：孩子答案匹配率。
- `fallback_running_rate`：端到端链路中进入异步复核的题目占比。
- `pending_rate`：端到端链路中仍处于待确认或复核中的题目占比。
- `final_judgement_rate`：最终已得到判题或 rubric 结果的题目占比。
- `average_latency_ms`：平均 OCR 调用耗时。
- `average_confidence`：模型返回的平均置信度。

私测阶段先积累真实照片样本，不把孩子真实作业照片提交到公开仓库；需要保留时应确认仓库和数据权限边界。

小程序确认页职责：

- 拍照或语音识别后进入统一确认页。
- 使用本地临时草稿传递长文本，避免把整段 OCR 文本塞进页面 URL。
- 显示识别题数和置信度。
- 允许用户编辑识别文本后再提交。
