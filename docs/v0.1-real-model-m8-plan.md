# 松果AI v0.1 M8 真实模型试用闭环计划

## 1. 目标

M8 的目标不是继续扩功能，而是把 v0.1 已有的 `MathMistakeTutorGraph` 接入真实大模型，验证小程序里的松鼠博士是否真的像 AI 老师一样自然追问，并且仍能完成结构化沉淀。

核心链路：

```text
微信小程序
  -> 松果AI后端
  -> MathMistakeTutorGraph
  -> DeepSeek API
  -> 答案泄露检查 / Schema 校验
  -> LearningMessage / LearningDeposit / 家长反馈
```

## 2. 当前模型选择

M8 本地试用先使用 DeepSeek：

```text
LLM_BINDING=deepseek
LLM_MODEL=deepseek-chat
LLM_HOST=https://api.deepseek.com
SONGGUO_AGENT_RUNTIME=langgraph
SONGGUO_SESSION_RUNNER=llm
SONGGUO_AI_ENGINE_PROVIDER=deepseek
```

API key 只写入本地 `.env`，不得写入 docs、测试、代码或提交记录。

## 3. M8 开发阶段

### M8-1：真实模型配置

要求：

```text
1. `.env` 能配置 DeepSeek API。
2. 后端默认服务能从 `.env` 读取 SONGGUO_AGENT_RUNTIME。
3. SONGGUO_AGENT_RUNTIME=langgraph 时走 MathMistakeTutorGraph。
4. SONGGUO_SESSION_RUNNER=llm 时构建 LLMSessionRunner。
5. 模型调用日志记录 provider/model/token/status。
```

验收：

```text
runtime=langgraph
runner_provider=deepseek
runner_model=deepseek-chat
tutor_graph_enabled=true
```

### M8-2：真实模型直连验证

要求：

```text
1. 用最小 JSON prompt 调用 DeepSeek。
2. 返回内容能被 LLMSessionRunner 解析为 LLMSessionOutput。
3. 失败时不崩溃，返回 fallback。
```

验收：

```text
deepseek_call_ok=true
```

### M8-3：当前题真实对话验证

要求：

```text
1. 创建三年级数学应用题会话。
2. DeepSeek 生成第一轮自然追问。
3. 孩子提交中间步骤时，DeepSeek 继续追问。
4. 孩子提交最终答案时，规则判题完成会话。
5. 完成后生成 1-3 道同类题。
```

验收：

```text
created_session=true
practice_count=3
deposit_saved=true
```

### M8-4：黄金题集

建立 20-30 道小学数学真实模型评测题，优先覆盖：

```text
限载进一
总价数量
倍数关系
有余数除法
周长面积
时间计算
单位换算
人民币计算
简单分数小数
多步应用题
```

验收：

```text
1. 每题都有题型、知识点、标准答案和预期错因。
2. 自动评估是否泄露答案、是否能自然追问、是否生成同类题。
3. 真实模型失败时记录原因。
```

### M8-5：家长反馈闭环

要求：

```text
1. 孩子完成一道题后生成 LearningDeposit。
2. 家长端能看到题目、错因、证据、同类题和建议。
3. DeepSeek 的自然总结必须经过后端结构化校验。
```

### M8-6：成本和日志

要求：

```text
1. 每次真实模型调用记录 provider。
2. 每次真实模型调用记录 model。
3. 每次真实模型调用记录 token_estimate。
4. 每次真实模型调用记录 status。
5. fallback 必须记录原因。
```

### M8-7：本地演示脚本

目标：

```text
1. 一条命令验证 DeepSeek 配置。
2. 一条命令跑三年级应用题后端演示。
3. 微信开发者工具可以直接打开小程序演示真实模型。
```

## 4. 当前已验证结果

截至 2026-05-04，本地已验证：

```text
1. DeepSeek 最小 JSON 调用成功。
2. 默认服务能读取 `.env` 并启用 langgraph。
3. MathMistakeTutorGraph 能用 DeepSeek 创建学习会话。
4. DeepSeek 能生成第一轮自然追问。
5. 模型调用日志能记录 deepseek / deepseek-chat。
6. 三年级春游大巴题真实模型演示通过。
7. 最终答对后由规则判题完成，token_estimate=0。
8. 自动化测试默认隔离真实模型，避免回归测试消耗 token。
```

## 5. 风险

```text
1. 真实模型可能输出最终答案，需要答案泄露检查兜底。
2. 真实模型可能不输出合法 JSON，需要 parser 和 fallback。
3. 真实模型话术可能过长，需要后续做儿童化压缩。
4. langgraph/langchain-core 安装会升级 packaging，当前与 safety 包存在依赖冲突；不影响运行测试，但后续需要整理依赖版本。
5. API key 只能保存在本地 `.env`，不能进入文档和代码。
```
